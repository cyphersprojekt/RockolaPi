# hardware

Gabinete imprimible de la rockola: el generador paramétrico (`gabinete.py`), las vistas
(`vista.py`) y los STL listos para imprimir.

La guía completa (piezas, impresión, armado, ajustes) está en **[docs/gabinete.md](../docs/gabinete.md)**.

```bash
pip install -r requirements.txt
python gabinete.py --vista      # regenera los STL y las imágenes de docs/img/
```
